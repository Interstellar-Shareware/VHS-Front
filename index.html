VHS

Very (un)Helpful Stats [Beta]

A Whatpulse stats tool by Interstellar Shareware



Very (un)Helpful Stats is a tool that turns your Whatpulse stats into significantly less helpful stats. This started with me tracking my mouse distance to the Moon in my geek window, then it spiraled rapidly from there. But I got to learn Node.js and some design stuff, so it all evens out. Input a username to view that user's stats, adjust the settings below, or enable 'team data' to view the user's team. More to come, but you can leave suggestions in the Issues tab of the GitHub page below!
